# Programming Fundamentals

A collection of laboratory work, assignments, practice programs, projects, and learning resources completed as part of the **Programming Fundamentals** course. The repository documents the progression from basic programming concepts to more structured problem-solving and implementation.

## Overview

The coursework focuses on developing a strong foundation in programming and computational problem solving. It includes regular laboratory exercises, assignments, independent practice code, projects, and additional resources used throughout the course.

## Repository Structure

```text
PF-Course/
├── Class/
├── assignments/
├── pf labs/
├── practice resources/
├── practices/
└── projects/
```

## Course Topics

The coursework covers fundamental programming concepts, including:

* Variables and data types
* Input and output
* Operators and expressions
* Conditional statements
* Loops and iteration
* Functions
* Arrays
* Strings
* Pointers and memory concepts
* Structures
* File handling
* Basic problem solving and algorithmic thinking
* Modular programming
* Debugging and code tracing

## Laboratory Work

The `pf labs` directory contains the practical laboratory exercises completed throughout the course. These exercises provide hands-on practice with fundamental programming concepts and progressively build programming and problem-solving skills.

## Assignments

The `assignments` directory contains coursework assignments designed to apply programming fundamentals to structured problems.

## Practice & Resources

The repository also contains additional material beyond formal coursework:

* **`practices/`** — Additional programming practice and problem-solving exercises
* **`practice resources/`** — Supporting resources used for learning and practice
* **`projects/`** — Larger programming exercises and projects
* **`Class/`** — Material and code related to classroom work

## Learning Outcomes

Through the coursework and practice, this course provided experience in:

* Building programs from fundamental programming constructs
* Developing structured solutions to programming problems
* Using functions and modular code organization
* Working with arrays, strings, pointers, and structured data
* Applying logical and algorithmic thinking to programming problems
* Debugging and testing programs
* Translating problem statements into working implementations
